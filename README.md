# ellure

Personal Command Center & Finance Tracker for Students.

- **Frontend:** Vite + React + TypeScript + Tailwind CSS
- **Local-First Architecture:** Persistent IndexedDB storage via Dexie.js
- **Finance Command:** Unified UPI & Cash tracking, strict double-entry ledger, loans & net worth
- **Student Dashboard:** Course tracking, academic tasks, habits, and goals
- **Privacy First:** Zero cloud tracking, client-side encryption and storage
- **Vercel Ready:** Pre-configured with SPA rewrites for instant deployment
